# Project-centered Fusion workspace

NarratoAI will make a durable Fusion Project—not a browser session or background task—the ownership boundary for the Film Vision Fusion workflow. One project produces one intended commentary video, may reference multiple Local Source Videos, owns uploaded Managed Project Assets and generated artifacts, and exposes its work through the Project Library and Fusion Project Workspace; this keeps refresh recovery, versions, review decisions, rendering, and deletion semantics coherent without copying multi-gigabyte local source files.

Legacy tasks and evidence artifacts are imported only through an explicit Migrated Fusion Project flow. Deleting a project never deletes referenced Local Source Videos, and destructive removal of managed, rendered, or otherwise non-rebuildable project outputs requires a separate confirmation.
