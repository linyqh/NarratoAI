# Gated, stage-based Fusion workflow

The Fusion Project Workspace will use freely navigable Fusion Workflow Stages rather than a one-shot wizard or an unrestricted editor. Creators may inspect setup, evidence, narration and Narrative Map, matching, review, and output at any time, while durable prerequisites and Review Checkpoints gate only the actions that would consume work or make downstream results authoritative; this supports recovery and investigation without permitting unsafe progression.

Ordinary project configuration saves immediately, while narration, Narrative Map, and timeline edits remain Content Drafts until an impact preview is accepted. Applying a draft creates a version and invalidates only dependent work. Background tasks continue when the creator leaves the project, appear in a global Task Center, and are summarized inside the owning project.
